in this system now there are three roles as Admin, Staff User and Driver,
So the access levels should be different from each other,

==== Admin =====
Has all the access to the system
Tabs:-
-Dashboard
-Orders
-Customers
-Drivers
-Transport
-PayNow
-Invoice Management
-Deductions
-Items
-Expenses
-reports
-Recent Actions
-Settings

Can Access, Add New, Delete Existing, Edit Existing or any other all the fuctions can be done by Admin


=== Staff User ====

Tabs:-
-Dashboard - full
-Orders - Add and Edit Only (No Delete Access)
-Customers - Add and Edit Only (No Delete Access)
-Drivers - Add and Edit Only (No Delete Access)
-Transport - View Only (No Add Edit or Delete)
-PayNow - Add and Edit Only (No Delete Access)
-Invoice Management - No Access
-Deductions - View Only
-Items - Add and Edit Only (No Delete Access/ No Quotation or Print Catalogue Access)
-Expenses - Add and Edit Only (No Delete Access)
-reports - No access
-Recent Actions - No access
-Settings - Limited access (text size, dark/light mode)

=== Driver ===

-Transport - Add or Edit Access (No Delete Access)
-Customers - Add and Edit Only (No Delete Access)
-Orders - view and print only (No delete or edit or add new)
-Settings - Limited access (text size, dark/light mode)

No access to other tabs



#### Backup and Restore or Import ###

only admin can backup, restore , or import anything in the system
